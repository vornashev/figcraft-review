# Material UI · component rules

Use Material UI components and the configured theme together. The bundled theme is createTheme from @mui/material 9.5.0; keep the installed project version when it differs. Material UI is not the Google Material 3 kit.

| Component | Properties / anatomy | Local baseline and bindings |
|---|---|---|
| Button | variant: text, outlined, contained; color; size; startIcon / endIcon; disabled | Medium contained ~36px recipe, shape.borderRadius 4px; palette.primary.main / contrastText; typography.button |
| TextField / OutlinedInput | Label, input, notched outline, helper text, error; small / medium | Medium 56px, small 40px recipe; primary focus outline, palette.error.main validation |
| Paper / Card | Elevation or outlined surface; content and optional actions | palette.background.paper; shape.borderRadius; use the selected theme shadow rather than an unrelated CSS shadow |
| Tabs / Table | Selected tab indicator; table header/rows/selection | palette.primary.main indicator; palette.action.selected row fill; palette.divider separators |

Use typography.body1 (16px/24px) for normal prose, body2 (~14px/20px) for the specimen, h5 (~24px/32px) for its heading and typography.button for control labels. MUI's default button text is uppercase with its own tracking; retain the theme override if the project changes that. Spacing is generated by the theme (default 8px unit); the resolved samples spacing.0–spacing.12 are local.

Centralize repeated visual changes in theme.palette, theme.typography, theme.shape and theme.components. Do not copy a purple Material 3 palette into MUI and imply they are identical. The retained Button/OutlinedInput/InputBase source supplies variants and disabled/focus treatment. The code library and commercial design-kit access are separate; drawing the local specimen does not require purchasing a kit.
